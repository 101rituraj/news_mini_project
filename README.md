# News Search & Headline Dashboard

A responsive, dark-themed full-stack news web application built with **Flask**, **Jinja2**, and the **GNews API**. It features dual-mode functionality allowing users to either search real-time news headlines by keywords or filter top headlines by country, category, and date ranges.

---

## Features

⭕ **Dual-Mode Navigation:** Easily switch between real-time keyword search and structured headline filtering.
⭕ **Advanced Filtering:** Filter articles by country, category (`general`, `business`, `technology`, etc.), and custom `From`/`To` date ranges using ISO 8601 formatting.
⭕ **Interactive UI/UX:** Designed with a modern dark theme, custom text/datalist/date inputs, and integrated SVG search icons.
⭕ **Rich Article Cards:** Includes fixed-size image containers, source attribution badges linked directly to external sites, publication date badges, and category labels.
⭕ **Direct Links:** Includes direct link to full article (`Read Full Articles`), direct link to publisher website (`Time Of India`, `Variety` etc.),

---

## Tech Stack

⭕ **Backend:** Python, Flask,
⭕ **Frontend:** HTML5, CSS3, Jinja2 Templating
⭕ **API:** GNews API (`/api/v4/search` & `/api/v4/top-headlines`)
